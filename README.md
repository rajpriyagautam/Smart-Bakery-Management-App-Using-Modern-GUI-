# 🍰 Sweet Bakery App

Hi 👋 I'm a beginner developer, and this is my **first project on GitHub**.
I built this project while learning Python and GUI development.

## 📌 About the Project

This is a bakery billing system made using Python. It allows users to:

* Select bakery items
* Add quantities
* View total bill
* Generate customer invoice (Excel file)
* Save owner records

## 🛠️ Technologies Used

* Python
* CustomTkinter (GUI)
* OpenPyXL (Excel handling)
* PIL (Image handling)
